<h1 align="center">Duo Click</h1>
<p align="center"><strong>双键一按，框选即复制。</strong></p>
<p align="center"><a href="README.md">English</a> · 简体中文</p>

一个轻量的 Windows 截屏工具。按住鼠标左右键并拖动框选，松开两个键，截图就会复制到剪贴板，随时粘贴到聊天窗口、文档或图片编辑器。

## 下载

**[下载 Windows 版 Duo Click](https://github.com/DylanZhangzzz/DuoClick/releases/latest)**

选择 `DuoClick-…-Windows.zip`，解压后打开 `DuoClick.exe` 即可，无需安装。请将 `DuoClick.exe.config` 与程序保存在同一个文件夹。

支持 Windows 10 / 11，需要 .NET Framework 4.8。

## 开始截屏

1. 在系统托盘找到蓝绿双色的鼠标图标；它可能收在 **^** 隐藏图标里。
2. 将鼠标移到选区起点，**同时按住左键和右键**，先按哪一个都可以。
3. 拖动鼠标，框选需要的区域。
4. **两个键都松开**后，截图自动复制到剪贴板。
5. 在支持图片的应用中按 **Ctrl + V** 粘贴。

按 **Esc** 可取消。本工具的手势是左右键一起按住，不是连续双击同一个键。

## 语言和托盘菜单

右键托盘图标，可暂停或恢复截屏、查看使用说明、退出程序。在 **Language / 语言** 子菜单中选择 **English** 或 **简体中文**，立即生效，下次启动也会记住。首次启动时按 Windows 显示语言自动选择中文或英文。

复制成功后，图标提示会短暂显示“已复制”，随后恢复为当前的就绪或暂停状态。

## 使用提示

- 截图只留在本机，不会上传，也不会自动保存成图片文件。
- 普通鼠标单击照常使用。组合键的第一次按下可能传给下方应用，请留意框选起点。
- 取消截屏或选区过小时，保留原来的剪贴板内容。
- 桌面在显示选区遮罩前截取，动态画面可能与按键瞬间存在短暂时间差。
- 受保护的视频、Windows 安全桌面及禁止截屏的应用可能无法截取。不同缩放比例的多显示器组合仍需进一步实机验证。
- 更新版本时，请先从托盘菜单退出旧版，再打开新版程序。
